# resumo-projetos

Repositório criado para agilizar o entendimento dos projetos pinados na página inicial.

## Projeto 🔧 [go-doc-agent](https://github.com/amonvix/go-doc-agent)

Motor determinístico para gerar documentação técnica em projetos Go.  
Demonstra análise de AST, automação e geração de README/comments.

**Stack:** Go • CLI • AST • Automation

---

## Projeto ✨ [terraform-ecs-microservices](https://github.com/amonvix/terraform-ecs-microservice)

Infra como código para provisionar microserviços no AWS ECS com Terraform.  
Demonstra arquitetura em nuvem, módulos Terraform e boas práticas de DevOps.

**Stack:** Terraform • AWS • ECS • IaC

---

## Projeto 🚀 [Titanic Survival Prediction](https://github.com/amonvix/titanic-survival-prediction)

API de ML para predição de sobrevivência (Titanic), com FastAPI, Docker, CI/CD e Terraform.  
Demonstra integração entre ML, backend, DevOps e IaC em um fluxo “production-like”.

**Stack:** Python • FastAPI • ML • Docker

---

## Projeto 📐 [Java Modular (JPMS)](https://github.com/amonvix/modularidade-java)

Arquitetura modular em Java com JPMS, separando contratos, implementações e consumidores.  
Demonstra desacoplamento, ServiceLoader e encapsulamento entre módulos.

**Stack:** Java • JPMS • Modular Architecture

---

Repositório de certificados e trilhas de estudo organizadas por tema.  
Demonstra aprendizado contínuo e evolução técnica.

**Stack:** Coursera • Certificates • Learning
